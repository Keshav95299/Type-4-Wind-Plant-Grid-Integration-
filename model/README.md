# PowerFactory model export

`Wind_Plant_Grid_Integration.pfd` is a copy of the **user-provided** PowerFactory project export. It has been included unmodified. The `.pfd` file was **not executed or validated** in this package-building environment.

Import it using a compatible licensed DIgSILENT PowerFactory installation, then confirm dependencies, control composite service status, study cases and event settings before attempting to reproduce the published results.

**Sharing caution:** PowerFactory projects can reference vendor, library, or other third-party assets. Check distribution rights before putting this file in a public repository. If you are unsure, do not publish this file; publish the documented study and results instead.

The single-line diagram for the 10-MW load-flow cases and the reduced 2-MW model cases are documented separately in the top-level README.
